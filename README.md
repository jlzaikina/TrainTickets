# Сервис бронирования ЖД билетов 

Веб-приложение для бронирования железнодорожных билетов с архитектурой MVC.  
Проект включает Swagger-документацию API.

---

## 🛠 Технологии
- **Backend**: ASP.NET Core MVC
- **Документация API**: Swagger/OpenAPI
- **База данных**: PostgreSQL (Entity Framework Core)
- **Frontend**: CSS, HTML, JS

📋 Функциональность

👤 Пользовательский функционал

- ✅ Регистрация и авторизация
- ✅ Просмотр расписания поездов
- ✅ Поиск и выбор рейсов
- ✅ Бронирование билетов
- ✅ Личный кабинет:
    - Редактирование профиля
    - Управление пассажирами
    - Просмотр истории бронирований
    - Скачивание электронных билетов (PDF)
      
👨‍💼 Административный функционал
- ✅ Управление рейсами и расписанием
- ✅ Создание новых поездов
- ✅ Создание новых схем вагонов
